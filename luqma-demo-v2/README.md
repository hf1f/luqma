# Luqma (لقمة)

منصة طلبات المطاعم عبر محادثات واتساب بدون عمولة (0% Commission).

## الإصدارات (Versions):

- **main**: الإصدار الأول (v1.0 - MVP Demo الأساسي القديم).
- **ersion-2 / 2**: الإصدار المطور (v2.0) — يشمل:
  - تصميم واستعراض تفاعلي بأسلوب Apple ومعارض السيارات الحديثة.
  - شريط تنقل فرعي مثبت (Sticky Sub-Nav) يتتبع التمرير.
  - شريط المواصفات والأرقام البارزة مع عدادات رقمية تصاعدية (0% عمولة، 3x سرعة، 100% امتلاك البيانات).
  - سلايدر بطاقات أفقي تفاعلي (Horizontal Card Carousel).
  - تبويبات تفاعلية لاستعراض محركات البرجر والبيتزا والمشروبات.
  - خط ثمانية الرسمي السعودي (Thmanyah Font Family) المدمج مع دعم تنعيم الحواف بدقة.
  - نظام Dark / Light Mode متكامل وفوري مع حفظ التفضيل.
  - مبدل لغة ثنائي (العربية والإنجليزية) بجانب زر الدارك مود.
  - محاكي iPhone 16 Pro تفاعلي متجاوب ومصغر ليناسب الشاشة بالكامل دون اقتطاع.

## تشغيل الديمو (How to Run):
افتح index.html (أو luqma-demo/index.html) مباشرة في أي متصفح ويب.
