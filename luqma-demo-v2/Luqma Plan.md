# خطة تنفيذ مشروع لقمة MVP

## 1. هدف المشروع

إنشاء ديمو ويب يحاكي تجربة طلب الطعام عبر بوت WhatsApp لمطعم واحد، بهدف عرض الفكرة على المستثمرين.

اسم المشروع المؤقت: **لقمة | Luqma**

لن يكون هناك ربط حقيقي مع WhatsApp أو الدفع في هذه المرحلة؛ التجربة ستكون محاكاة تفاعلية كاملة على الويب.

## 2. تجربة المستخدم

الترحيب → اختيار اللغة → اختيار توصيل أو استلام → عرض المنيو → اختيار الصنف → تحديد الكمية → الإضافات والملاحظات → مراجعة الطلب → بيانات العميل → طريقة الدفع → دفع تجريبي → تأكيد الطلب.

## 3. واجهة العميل

### شاشة المحادثة

- تصميم يشبه WhatsApp.
- رسائل البوت وأزرار تفاعلية.
- دعم العربية والإنجليزية.
- دعم RTL للعربية وLTR للإنجليزية.
- زر الرجوع وإعادة البداية وعرض السلة.

### شاشة المنيو

- صورة الصنف.
- الاسم والوصف والسعر.
- التصنيفات.
- الإضافات والخيارات.
- الكمية والملاحظات.
- إضافة وتعديل السلة.

التصنيفات التجريبية: البرجر، البيتزا، الوجبات، المقبلات، المشروبات، الحلويات.

## 4. بيانات العميل

### التوصيل

- الاسم.
- رقم الجوال.
- المدينة أو الحي.
- العنوان.
- ملاحظات التوصيل.

### الاستلام

- الاسم.
- رقم الجوال.
- وقت الاستلام المتوقع.
- ملاحظات إضافية.

## 5. الدفع التجريبي

عرض الخيارات التالية: الدفع عند الاستلام، بطاقة بنكية، Apple Pay، Tabby، Tamara.

الدفع الإلكتروني سيكون محاكاة فقط، ولن يتم تخزين أو معالجة بيانات بطاقة حقيقية.

## 6. صفحة المطعم

- عرض الطلبات الجديدة.
- تفاصيل العميل والطلب.
- نوع الطلب والإجمالي وطريقة الدفع.
- تغيير حالة الطلب.

حالات الطلب: جديد → تم القبول → قيد التحضير → جاهز → مكتمل.

## 7. صفحة المستثمر

- المشكلة.
- الحل.
- طريقة عمل لقمة.
- المميزات.
- مقارنة مع الطرق القديمة والمنصات الخارجية.
- زر تجربة الديمو.
- زر مشاهدة لوحة المطعم.

## 8. التقنية

- Frontend: Next.js + TypeScript + Tailwind CSS.
- دعم Responsive وRTL/LTR.
- بيانات تجريبية ثابتة في النسخة الأولى.
- تجهيز الهيكل مستقبلًا لإضافة FastAPI وPostgreSQL وWhatsApp Cloud API وبوابة دفع حقيقية.

## 9. الصفحات المطلوبة

- `/` صفحة تعريف المستثمر.
- `/demo` تجربة بوت العميل.
- `/menu` عرض المنيو.
- `/restaurant` صفحة الطلبات للمطعم.
- `/order/[id]` تفاصيل الطلب.
- `/success` تأكيد الطلب.

## 10. مراحل التنفيذ

1. تأسيس المشروع ونظام الألوان والخطوط ودعم اللغات.
2. بناء تجربة البوت: الترحيب، اللغة، نوع الطلب، والتنقل.
3. بناء المنيو والتصنيفات وتفاصيل الأصناف والسلة.
4. بناء بيانات العميل ومراجعة الطلب والدفع التجريبي.
5. بناء صفحة المطعم وإدارة حالات الطلب.
6. بناء صفحة المستثمر.
7. الاختبار على الجوال والكمبيوتر وتحسين التصميم.

## 11. معايير نجاح الـMVP

يستطيع المستخدم بدء المحادثة، اختيار اللغة، تصفح المنيو، إضافة وتعديل الأصناف، كتابة الملاحظات، اختيار التوصيل أو الاستلام، إدخال بياناته، اختيار طريقة الدفع، إكمال الدفع التجريبي، رؤية رسالة نجاح، وظهور الطلب في صفحة المطعم.

## 12. ما بعد الـMVP

1. ربط WhatsApp Cloud API.
2. نقل المنيو إلى قاعدة بيانات.
3. لوحة تحكم لإدارة الأصناف.
4. إشعارات المطعم.
5. الدفع الحقيقي.
6. الخرائط والعناوين.
7. دعم عدة مطاعم.
8. التقارير والكوبونات والعروض.

## القرار التقني

سنستخدم **Next.js + TypeScript** لبناء الديمو، مع تجهيز المشروع لاحقًا لإضافة **FastAPI وWhatsApp Cloud API**.
