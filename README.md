# Luqma (لقمة)

منصة طلبات المطاعم المباشرة عبر واتساب بدون عمولة (0% Commission).

## 📁 مجلدات المشروع (Project Versions):

- 📁 [**luqma-demo**](./luqma-demo) — **الإصدار الأول القديم (v1.0)**:
  - محاكي الطلب الكلاسيكي الأساسي.

- 📁 [**luqma-demo-v2**](./luqma-demo-v2) — **الإصدار الثاني المطور (v2.0)**:
  - استعراض تفاعلي بأسلوب Apple ومعارض التقنية الحديثة.
  - شريط تنقل فرعي مثبت (Sticky Sub-Nav) وسلايدر بطاقات أفقي.
  - عدادات رقمية تصاعدية (0% عمولة، 3x سرعة، 100% امتلاك البيانات).
  - تبويبات تفاعلية لاستعراض محركات البرجر والبيتزا والمشروبات.
  - خط ثمانية الرسمي السعودي (Thmanyah Font Family) مع تنعيم حواف الحروف.
  - نظام Dark / Light Mode فوري مع مبدل لغة ثنائي (العربية / English).
  - إطار هاتف ذكي مصغر متناسب مع الشاشة بالكامل بدون قص رأسي.
  - إبراز الخيارات المحددة في الوضع الليلي بلون أخضر زمردي بارز.
