# لقمة | Luqma

## فكرة المشروع

لقمة هو نظام طلب طعام يبدأ من تجربة محادثة شبيهة بواتساب. يختار العميل اللغة، ثم يختار التوصيل أو الاستلام، ويتصفح المنيو بالصور والأسعار، ويخصص طلبه قبل التأكيد.

الهدف هو إعطاء المطاعم قناة طلب مباشرة ومملوكة لها، بدل الاعتماد الكامل على المكالمات أو تطبيقات الطرف الثالث.

## المشكلة الحالية

بعض طرق وتطبيقات طلب الطعام تسبب تحديات للمطاعم، مثل:

- الاعتماد على المكالمات والموظفين لاستقبال الطلبات.
- أخطاء في تسجيل الطلبات والملاحظات.
- بطء الرد وقت الزحام.
- عمولات مرتفعة على كل طلب من بعض المنصات.
- عدم امتلاك المطعم الكامل لبيانات العملاء والطلبات.
- تجربة مختلفة ومشتتة للعميل بين تطبيقات متعددة.

## الحل الذي تقدمه لقمة

لقمة تقدم تجربة طلب رقمية مباشرة للمطعم:

- محادثة بسيطة تشبه واتساب.
- اختيار اللغة العربية أو الإنجليزية.
- اختيار توصيل أو استلام.
- منيو بصور وأسعار وتفاصيل واضحة.
- تخصيص كل صنف بشكل مستقل.
- إضافة ملاحظات مثل بدون طماطم أو الصوص على جنب.
- إظهار رسوم الإضافات قبل تأكيد الطلب.
- اختيار وقت الاستلام بناءً على الوقت الحالي.
- مراجعة الطلب وتعديله قبل الدفع.
- خيارات دفع قابلة للتوسع مستقبلًا.

## طريقة تجربة الديمو

1. افتح ملف `index.html` في المتصفح.
2. اختر اللغة من أزرار العربية أو English.
3. اختر نوع الطلب: توصيل أو استلام.
4. اختر صنفًا من المنيو.
5. جرب تخصيص الصنف والكمية والملاحظات.
6. أضف أكثر من نسخة من نفس الصنف بتخصيصات مختلفة.
7. افتح مراجعة الطلب وتأكد من ظهور تفاصيل كل صنف.
8. أدخل بيانات العميل واختر طريقة دفع تجريبية.

## مثال على التخصيص

يمكن للعميل اختيار:

- بيتزا صغيرة أو وسط أو كبيرة.
- نكهة البيتزا: بيبروني، دجاج رانش، خضروات أو مارغريتا.
- حرارة البيتزا: بدون فلفل، متوسط أو إكسترا.
- إضافات مدفوعة تظهر بسعرها قبل الإضافة.
- مشروب بنكهة وكمية ثلج مختلفة بدون رسوم إضافية.

## حالة النسخة الحالية

هذه نسخة MVP تجريبية هدفها شرح الفكرة وإقناع المستثمرين. لا تحتوي حاليًا على:

- ربط فعلي مع WhatsApp Cloud API.
- دفع إلكتروني حقيقي.
- قاعدة بيانات أو حسابات مستخدمين.
- لوحة تحكم متصلة ببيانات حقيقية.
- منيو قابل للتعديل من المطعم.
- نظام توصيل فعلي.

بيانات الطلب والدفع في الديمو تجريبية فقط.

## التقنية الحالية

- HTML لبناء الصفحة.
- CSS للتصميم المتجاوب.
- JavaScript للتفاعل وإدارة خطوات الطلب.

## التطوير المستقبلي

1. ربط WhatsApp Cloud API.
2. إضافة Backend وقاعدة بيانات.
3. ربط بوابات الدفع.
4. بناء لوحة تحكم كاملة للمطعم.
5. إرسال إشعارات الطلب للمطعم والعميل.
6. دعم عدة مطاعم.
