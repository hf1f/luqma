# Luqma

Luqma is a simple food-ordering chatbot demo for restaurants.

## What it does

- Lets customers choose Arabic or English.
- Supports delivery and pickup orders.
- Shows a menu with images, prices, and item details.
- Allows item customization and notes.
- Includes demo checkout and payment options.
- Provides pickup times based on the current time.

## How to run

Open `index.html` in a browser.

## Current limitations

This is an MVP demo only:

- No real WhatsApp connection.
- No real payment processing.
- No database.
- Demo data only.

## Files

- `index.html` — Main page
- `styles.css` — Styling
- `app.js` — Ordering logic
